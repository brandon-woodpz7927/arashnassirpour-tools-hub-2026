## Overview

arashnassirpour.com is a GitHub Pages user site that collects several public engineering tools under one landing page. It provides a common starting point for earthquake, structural engineering, and catastrophe risk resources, so users can move between related calculators and analysis utilities without locating each project independently.

Rather than functioning as one standalone calculator, the site acts as a shared directory and navigation layer. Its consistent layout helps visitors reach fault, response, design, and analysis tools, while custom-domain support provides a direct, branded way to publish the collection.

## Using the Site

The home page is the main directory for the engineering resources included in the project.

A normal visit looks like this:

1. Load the landing page.
2. Select an engineering category or linked tool.
3. Open the destination page for the applicable calculator, analysis view, or reference material.
4. Return to the hub whenever you need to move to another earthquake, structural, or risk-focused resource.

When developing locally, reload the browser after changing HTML, styles, or link destinations. This makes it possible to verify that each navigation item still reaches the intended page.
